# 附件四：首版四页面合同（非像素稿）

所有页面沿用产品事业部导航与平台鉴权；展示字段仅限后端当前用户授权可读内容。错误、未接入、无数据、待确认分别呈现；前端不得用静态数据伪造采集/资格通过。S1 优先实现页面 1、2、4；页面 3 在 S2 出现公告预检，在 S3 增加文件复核，不靠占位文案宣称已交付。

| 页面 | 必须展示 | 必须支持的操作和异常 |
| --- | --- | --- |
| **商机池** | 标题、地区、采购/招标方、预算及截止日（未知即显示未知）、公告来源与发布时间、最近变更、业务筛选结果；S2 后展示“公告预检”及硬门槛待确认/不满足提示 | 打开项目、按来源/阶段筛选；来源采集故障或长期无更新须有醒目提示，不用“0 项”表示正常；列表只能预览授权摘要 |
| **项目详情** | 项目稳定标识、所有原公告链接与来源、公告事件时间线、历史快照差异、文件入口及状态（待获取/已取得/失效）、当前负责人与其人工决定及依据版本 | 查看允许访问的原文/附件；有权人员可关注、暂缓或忽略并填写理由；公告更正后提示重评；未授权原件与敏感字段不可泄露 |
| **资格匹配** | 明确标“公告预检”或“完整文件复核”；逐条列要求原文、类别、硬软、定位、企业证据名称/版本与授权可见的原件入口、结果（三态）、原因、核实人/时间、待复核提示；硬门槛不满足单独置顶 | 按资格类别筛选，查看双向证据、由有权人员核实/纠错并留理由；未取得文件显示“完整复核不可用”而不是“已通过”；无命中标待确认，不能点击结果就下载无权附件 |
| **来源运行状态** | 每来源批准范围、采集状态、最近尝试/成功时间、公告新增/空结果/失败区分、最近错误与告警处理状态、适用栏目及时间窗 | 有权限的运维查看失败/停采原因、追踪重试和处理记录；非运维人员只见必要健康提示，不暴露站点凭据、内部地址或敏感日志 |

**AT-TEN-UI**：权限不同的产品员工与运维人员看到各自获准字段；商机池未知截止日不造时间；详情保留更正前版本；资格页仅在 S3 文件已取得且条款核实后展示完整复核；站点超时与合法空结果在列表和运维页均可区分。由 T-TEN-14、T-TEN-23、T-TEN-33 验证；每批按已实现范围验收，不因 S1 暂缺 S3 内容判 S1 失败或提前标 S3 通过。
