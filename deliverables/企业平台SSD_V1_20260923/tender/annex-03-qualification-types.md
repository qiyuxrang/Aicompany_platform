# 附件三：准入材料类别与判断合同

以下为 S2/S3 共同的**类别清单**，不要求每类先建一张表。每条要求按招标原文逐项记录 `type`、来源/条款定位、阶段、硬软属性、核实状态、适用基准日、规则版本、候选公司证据版本和结果。材料可作为同一受控记录的不同类别；具体字段只在真实案例及业务规则确认后扩充，不编造通用评级体系。

| type | 最少要核对的事实 | 不可自动判满足的例子 |
| --- | --- | --- |
| `ENTERPRISE_QUALIFICATION` 企业资质 | 持证主体、资质类别、等级、适用范围及有效期 | 同名但不同类别；证书到期；等级顺序未获确认 |
| `PERSONNEL_CERTIFICATE` 人员证书 | 人员、专业/等级、注册或任职主体、期限及是否满足岗位要求 | 有证却不在要求的注册单位；人员不可用或未核实 |
| `PROJECT_PERFORMANCE` 企业业绩 | 项目主体、行业/类别、合同金额、完成时间及证明材料 | 有合同但缺验收材料；金额/数量或时间窗不能证实 |
| `FINANCIAL_CONDITION` 财务条件 | 具体财务指标、期间、审计材料及主体 | 没有获授权的财报、币种/口径不明 |
| `CREDIT_CONDITION` 信用条件 | 要求的信用主体、查询时点、记录与合法可查证据 | 未查到负面记录即推断信用合格 |
| `MANUFACTURER_AUTHORIZATION` 厂家授权 | 指定厂家/产品、被授权主体、项目或地域范围、有效期及原件 | 仅有经销关系、授权书未取得或适用项目不明 |
| `OTHER_ADMISSION_MATERIAL` 其他准入材料 | 招标具体文字、材料形式及核对者 | 不认识类别时模型自行创设满足规则 |

每类仍适用 SDD 三态：只有已核实且适用的正向证据能支持满足；权威反证或经授权人员基于受控完整记录核实缺失才可能判不满足；检索无命中、材料缺失但未能证明不存在，一律待确认。资格判断与“能否投”不等价；联合体、地域限制等按实际招标条件记入 `OTHER_ADMISSION_MATERIAL`，没有批准的结构化规则时由人工核对。

**AT-TEN-QT**：七类分别能显示招标条件及证据状态；厂家授权未找到只待确认，过期或不适用该项目的授权不能满足；财务/信用未经核实不能满足；业绩数量、金额与时间窗须同时成立；类别未知不得悄悄忽略。由 T-TEN-21/22 与 T-TEN-32 承担验证。
