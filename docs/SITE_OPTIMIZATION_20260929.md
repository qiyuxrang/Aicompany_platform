# PC 全站优化验收记录（2026-09-29）

本次按 PC 工作台范围优化，覆盖产品、工程造价、人力资源、经营管理、平台运维及管理员预览；未新增手机端功能。桌面验收分辨率为 1280×800、1440×900、1920×1080。

## 改动

- 部门工作台和产品重页面按需加载；增加加载状态与异常恢复入口，工作页面异常时保留可用导航。
- 页面标题显示当前部门与栏目；运维页显示网络状态；返回浏览器标签页时刷新权限或产品概览。
- 产品概览按侧栏之外的实际可用宽度调整布局，修复人力资源侧栏文字和运维选中图标的颜色覆盖。
- 区分蓝图审核与最终成果审核的待办提示。
- PPT 优先抽取各章正文与表格，防止目录标题占满摘要；无图片时在指定区域排版，避免覆盖旁边的文字；质量门禁要求每份有正文的报告都包含正文映射。
- PPT 缓存加入渲染器指纹，生成器升级后重新生成；保留历史产物与 Word 缓存。
- Windows 回归脚本使用已安装的本地前端工具；新增隔离 PC 浏览器验收脚本，以合成数据运行，不读取生产业务数据。
