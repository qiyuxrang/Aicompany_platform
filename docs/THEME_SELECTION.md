## 使用与边界

- 首次刷新日常18210入口即可加载切换按钮；之后切换即时生效，不刷新页面、不清空当前表单准备稿。
- 偏好保存在当前浏览器、当前站点的 localStorage `theme`，与 Django Admin 原生主题键共用；进入后台或返回门户沿用显式浅色/深色选择。后台原有“自动”值在门户按默认日间处理，不新增跟随系统功能。
- 不同步到账号或其他设备。浏览器禁止存储时仍可在当前页面切换，但不保证下次访问记忆。
- 初始化脚本在前端加载前设置主题，降低深色偏好下首屏亮底闪现；页面失焦返回、历史导航及其他标签页偏好变更会同步。
- 只保存风格，不保存密码或业务草稿。不改变已有“刷新/离开工作台清空准备稿”边界。
