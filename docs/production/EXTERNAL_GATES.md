# 外部依赖与后续门槛

本文件记录现场依赖与验收条件，不把它们混入代码完成率，也不声明现场验证已完成。当前范围与授权以 [SPEC](../SPEC.md) 第9节及获批 Agent 规则为准，任务证据仅登记在[唯一执行状态](../../项目规划/Agent平台/2026-09-30-agent-platform-status.md)。已授权范围内的实现和隔离验证连续推进；缺少外部环境只阻塞依赖该环境的验收，不新增中途审批或成稿二次审批。

## 独立 Agent Runtime 与前置隔离

Agent 默认关闭；开启 `PORTAL_AGENT_ENABLED` 不等于启动或连通 Runtime。需要部署独立 LangGraph Runtime、获准服务地址与允许名单、服务端鉴权凭据、锁定版本的 Harness/模型适配、持久检查点、隔离运行文件/Store 和主子运行恢复配置。开发进程、内存后端和模拟 Runtime 不作为云生产持久化证据。Web、原产品/HR Worker、Agent Runtime 分别核对健康与进程生命周期，原流程保持可用。

真实资料试点前须先通过 AG-15 默认工具、主子运行及恢复后的文件/Store/检查点/共用 Skills 隔离，以及 AG-16 持续成功循环、领域派生和跨恢复的根累计有限终止；证据须包含实际工具清单、配置来源、根子关联、跨账号拒绝和本人正常路径。业务 API 权限、网关限频、单个领域任务上限不能替代这些证明。未配置/未启用时保持明确未执行；提交超时或未知时先核对记录，不以消息接收冒充实际完成。

## 真实模型

需要运维人员提供获准的 OpenAI Chat 兼容 HTTPS 服务地址、模型标识、网关外发允许名单、密钥环境变量和费用上限。平台管理员完成连接测试后才能启用业务路由。测试密钥、个人账号和聊天中的明文凭据不得用于生产。

## 人事质量验收

需要HR提供获准当前试点的JD、文本简历、DOCX、原生PDF、扫描PDF及人工基准判断。可用实际资料不强制脱敏，但必须明确对象与外发范围，先满足 AG-15/16，并使用获准模型；不扫描全库或收集无关隐私。合成/脱敏契约测试与真实资料质量分开登记。验收关注事实提取、引用证据、UNKNOWN比例和人工可解释性，不用“模型评分与人工完全一致”作为虚假目标。

招聘资料实行长期授权归档，不自动按15天到期。升级需核对有效存量授权、版本和原件；旧规则已失效 `legacy_expired`、人工删除和文件缺失资料不得自动恢复。文件维护仅清理孤立临时/待删除文件，不把归档时间作为删除有效原件的依据。

## RAGFlow

需要正式检索URL、服务端Token、用户到知识库/文档的授权映射及授权版本。未满足时保持 `source_only_preview`，正式模式必须失败关闭。

## 工程系统

本地成本草稿与外部工程系统接入分别验收。本地成本草稿需要获准的 Python/CLI、私有目录、样例清单以及工程人员对结果的核对；已配置且通过任务验证的环境不再统一描述为“工程未接入”。正式报价和自动定额审定仍未开放。

外部工程系统的单点登录和数据回流仍需要工程同事提供测试/正式地址、一次性身份兑换协议、用户角色字段、项目状态枚举、只读回流字段、超时与错误码。未完成这项联调，不宣称外部系统已接通。

## 文档与台账业务签收

三件套渲染、哈希和引用关联检查不等于项目事实正确。产品所有者确认蓝图精确版本后继续生成、查看和下载三件套，无第二审核人或成稿二次审批；业务质量签收独立记录，不阻断 Agent 交付完成或查看下载。正式技术方案至少50000、可研至少70000个非空白正文字符，同时核对实际内容和来源，不用重复扩写或虚构数据凑篇幅。PPT 是两份报告的摘要，来源标记仅覆盖实际选用内容，不声明覆盖全文；正式使用前仍须核对正文、图表、版式和遗漏事项。合成样例和替代模型审核的隔离验收不能代替真实项目质量签收。

财务人员须核对实际源表、金额单位、日期、回款和逾期口径，由填写人确认发布本人精确修订与发布基线，无第二审核人。工程与财务看板只读已发布版本；售前按产品约定显示最新保存的工作数据，必须保留草稿/未审核标识，不视为正式经营结论。总经理按获准业务引用只读摘要、成果和原文，不获得代发布、修改、完整员工聊天或个人记忆权限。

## 生产基础设施

需要正式域名、TLS证书、反向代理可信peer、PostgreSQL生产实例、加密备份介质、日志/指标平台、告警接收人和维护窗口。平台脚本与文档只能准备流程，不能代替基础设施负责人现场确认。

需核对 Web、HR/产品 Worker、Agent Runtime、模型网关、数据库及私有文件/检查点的部署拓扑、资源限制、进程恢复、健康检查、密钥配送轮换和私网边界。云安全配置、依赖镜像、隔离迁移与真实云发布分别记录；本文件不声明已执行生产迁移、部署或恢复。

## 容量、压力与灾备冻结

并发人数、并行长任务数量、请求/任务配比、资料规模、云规格和目标成本尚待冻结。以下为候选技术指标，不是容量承诺或已通过结果：目标负载连续2小时，普通查询P95≤1s、普通写入P95≤2s、意外失败率≤0.1%；2倍目标负载阶梯/过载、5倍短时突发；24小时混合稳定；灾备RPO≤5min、RTO≤30min。长任务独立测排队、吞吐、完成率、取消/恢复和实际模型/渲染耗时，不套普通接口响应时限。

测试应同时保留总请求、预期权限/限流/过载拒绝、意外失败、超时和5xx分项，记录分位数、队列、CPU/内存/连接/存储趋势、饱和点与恢复时间。PostgreSQL并发必须在独立真实 PostgreSQL 多连接验证，SQLite跳过不能作为通过证据；外部服务压力仅针对获准目标和窗口，不对公开商机来源压测。备份恢复必须恢复数据库、原件、版本与检查点并验证hash和授权，不能以备份文件存在证明RPO/RTO。

全量回归、角色E2E、压力、故障、外部依赖、云安全、灾备、告警与放行各类别见[验收矩阵](ACCEPTANCE_MATRIX.md)。只有当前版本、当前环境实际执行的证据才能登记为通过；历史测试计数和“容器启动成功”均不能替代这些门槛。
