# 企业智能体平台生产基线

冻结日期：2026-09-28。

本基线覆盖本轮获准实施的阶段：生产范围冻结、统一模型平台、人事部生产化、部门台账录入与总经理看板、平台侧安全与运维加固。RAGFlow 正式联调、外部工程系统接入、最终跨系统压力测试、用户验收和正式发布不在本轮完成声明中。

## 1. 产品边界

| 模块 | 本轮生产基线 | 不得误报为已完成的事项 |
| --- | --- | --- |
| 公共平台 | 统一登录、首次改密、部门与细粒度业务授权、审计、模型网关、健康检查 | 正式域名、证书和生产告警接收人仍需部署现场确认 |
| 产品事业部 | 保持现有资料、蓝图三轮审核、三件套生成和格式基线 | RAGFlow 未取得真实地址与凭据前不得标记正式检索通过 |
| 人事部 | JD、渠道文案、简历批次、真实模型路由选择、证据化评分、15天清理 | 模型输出不得作为自动录用或淘汰决定；无真实凭据时不得声明质量验收通过 |
| 工程部 | 保持独立系统接入边界，本平台预留身份、模型与数据契约 | 不在本仓库重写同事负责的工程业务系统 |
| 经营台账 | 工程、财务、售前人员在平台内录入、导入、提交和发布；总经理读取最新已发布版本 | 不再依赖外部财务、CRM或工程数据接口；草稿不得进入总经理正式指标 |

## 2. 数据状态基线

经营台账统一采用“草稿 → 已提交 → 已发布”状态。获准发布人员可以退回已提交版本；发布后形成不可变版本。录入人员继续修改时创建或更新后续草稿，不覆盖总经理正在查看的正式版本。

总经理看板中的金额、数量、逾期和分布由确定性程序计算。模型可以总结已发布数据，但不得写回台账、替代财务口径或生成缺失数字。

招聘需求、对话、JD、筛选批次、简历原件和衍生结果沿用15天保留规则。更新、重试和模型切换不延长保留期。转正档案、审计事件、经营发布版本不属于该清理范围。

所有写操作必须由后端重新检查账号状态、首次改密状态、角色/授权版本和对象版本。隐藏菜单、直接访问 URL 或前端传入角色都不能扩大权限。

## 4. 模型基线

管理员维护服务商、模型和业务路由。密钥只存在模型网关运行环境，数据库只保存环境变量名称；浏览器只获得不透明模型 ID、业务显示名、能力和配置版本。

| 部门 | 固定业务路由 |
| --- | --- |
| 产品 | `product_blueprint`、`product_writing`、`product_review`、`product_knowledge` |
| 人事 | `hr_jd_draft`、`hr_resume_parse`、`hr_resume_extract`、`hr_match_summary` |
| 总经理 | `manager_analysis`、`manager_report`（启用时） |
| 工程 | 后续接入契约保留，不在本轮调用 |

每个路由有一个默认模型和零个或多个获准候选模型。用户可选择的仅限其部门和授权范围。异步任务必须保存模型不透明 ID 与配置版本；调用前后配置或授权变化时丢弃结果并明确失败。

## 5. 质量与格式基线

产品三件套继续执行已冻结的交付规范：测试技术方案约3000字且不少于15张已渲染图、测试可研约5000字且不少于20张已渲染图、PPT为5页商务科技风；Word使用普通页边距、黑色字体、页眉页码、至少二级目录、一级章节另起页，图表内嵌相应章节且不保留 Mermaid 源码。

HR模型输出必须通过严格结构校验；没有原文证据的字段为 `UNKNOWN`。年龄和出生日期只允许作为人工备注，不进入自动评分或排除逻辑。

## 6. 生产完成定义

本轮代码完成需同时满足：

1. 新旧数据库迁移链无分叉，空库迁移和迁移漂移检查通过。
2. 后端、前端、模型网关自动化测试通过；PostgreSQL 专用项若未运行必须明确记录。
3. 新增写接口具备权限、CSRF、对象版本、幂等或并发冲突保护。
4. 前端不暴露服务商地址、远程模型标识、密钥环境变量或密钥。
5. 经营草稿不影响总经理看板，只有最新已发布版本可见。
6. HR原件和结果保持用户隔离，过期访问立即拒绝，物理清理可重试。
7. 配置缺失和外部服务失败采用失败关闭，不填充演示结果。
8. 部署、备份、恢复、监控和回退步骤有可执行文档。

真实模型质量、RAGFlow、工程外部系统、正式 TLS、生产备份恢复和最终用户签收必须在获准环境另行验收，不以单元测试替代。
