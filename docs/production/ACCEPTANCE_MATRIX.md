# 生产候选验收矩阵

## 本轮必须通过

| 编号 | 范围 | 验收点 | 证据 |
| --- | --- | --- | --- |
| P1 | 范围治理 | 生产基线、权限矩阵、外部门槛均已冻结 | 本目录文档 |
| P2-01 | 模型管理 | 服务商、模型、路由、候选模型和默认模型可由管理员配置 | 后端管理与模型测试 |
| P2-02 | 模型选择 | 仅返回当前用户获准且启用的候选模型，不返回敏感配置 | API权限测试 |
| P2-03 | 模型固定 | 选择携带配置版本，配置或授权变化后旧选择失败关闭 | 并发/撤权测试 |
| P2-04 | 模型审计 | 调用状态、耗时和Token可追溯，不保存提示词、输出和密钥 | 日志测试 |
| P4-01 | JD | 默认/所选模型生成JD，编辑、确认、渠道适配仍保持版本约束 | HR API测试 |
| P4-02 | 简历 | 批次固定筛选模型，Worker重启、租约过期和失败重试不越权 | Worker测试 |
| P4-03 | 证据 | 无原文证据为UNKNOWN，敏感年龄不进入评分 | 匹配规则测试 |
| P4-04 | 保留期 | 15天后读取、修改、下载立即拒绝，文件清理失败可重试 | 保留期测试 |
| P6-01 | 台账权限 | 用户只能录入、提交或发布明确授权的部门台账 | 权限矩阵测试 |
| P6-02 | 台账并发 | 所有写入携带期望修订号，旧版本返回409 | API并发测试 |
| P6-03 | 发布隔离 | 工程/财务仅显示已发布版本；售前显示最新工作数据并明确草稿/未审核边界 | API与浏览器测试 |
| P6-04 | 指标口径 | 财务使用十进制定点，工程/售前状态与冻结口径一致 | 计算测试 |
| P6-05 | 审计版本 | 创建、修改、导入、提交、退回和发布可追溯 | 审计测试 |
| P7-01 | Web安全 | 首次改密、CSRF、会话撤销、HTTPS配置、上传边界有效 | 安全回归 |
| P7-02 | 数据安全 | 部门正文隔离，平台管理员不因管理身份自动读取业务正文 | 越权测试 |
| P7-03 | 运维 | 健康检查、Worker、清理、备份、恢复和回退步骤明确 | 部署检查 |

| 编号 | 依赖 | 未满足时的系统行为 |

## 发布否决条件

- 任一跨部门越权可读取正文或下载私有文件。
- 密钥、服务商凭据、提示词或模型正文进入调用日志。
- 草稿台账被总经理当作正式数据展示。
- 财务金额使用浮点数聚合或模型生成正式指标。
- Worker重试产生重复正式版本或旧租约覆盖新结果。
- 外部服务未配置时返回合成命中、合成经营数字或伪成功。
- 迁移链存在分叉或全新数据库无法迁移。
