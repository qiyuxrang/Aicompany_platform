# 部门工作台 UI 改造

日期：2026-09-29。

## 范围

- 登录后直接进入已授权角色对应的部门；保留有效的站内业务深链接、强制改密与管理员隔离。
- 保留侧栏菜单及工作区切换，右侧内容独立滚动。
- 产品首页改为最近项目、待处理事项及成果列表；数据继续来自原接口。
- 项目详情使用蓝图审批、技术方案、可研报告、汇报 PPT、项目资料、版本记录分区；保留审批绑定、版本校验、生成授权及下载规则。
- 知识库问答突出提问、历史会话、回答与引用，生成时禁止切换会话以保护在途请求标识。
- 删除常规页面中的测试预览、接口接入和平台架构介绍；实际权限、不可用、草稿与失败信息仍保留。
- 部门页面增加断网/恢复提示；恢复连接不会自动重放生成、审批或问答提交。

## 组件与主题

采用 `@radix-ui/react-tabs@1.1.21`（包元数据许可证 MIT）实现键盘导航及页签语义，适配现有 CSS 变量。此轮没有安装 shadcn CLI、Tailwind、Aceternity 或 Magic UI，不将使用 Radix 等同于已经集成这些库。避免为页签引入第二套全局主题或动画框架。

保留既有品牌、深浅色与状态 token；页面通过连续分区、统一排版和紧凑对象列表建立层级。新增动效与过渡遵守减少动态效果设置。

浏览器中的合成数据环境必须与真实接口分离；其中的问答或成果展示不代表真实模型、知识库、审批与文档生成服务已验收。真实业务页面需要有效账号；本轮不读取本地密码文件、不更改业务数据或账号权限。

保留原有未提交修改。本轮不修改后端接口、生成逻辑和部署配置。
