# 央国企招标采购官方渠道调研（2026-09-28）

本报告整理 15 家央国企采购平台候选，服务于全国商机看板的后续来源扩充。核验方式为 **web 搜索、打开官方页面及少量官方链接跳转**，没有批量抓取、登录、注册、购买标书、调用受限接口或写入业务数据库。本次未新增或启用任何采集来源。

“页面可读”仅表示本次 web 工具能提取相应公开内容；搜索索引可能滞后，也不代表项目运行环境已经通过 TLS、限频、分页、详情、日期完整性与七日窗口采集验收。下表的行业范围是平台采购覆盖范围，不代表每条公告都是信息化需求。

## 后续验证顺序建议

根据本次公开页面可读性，优先对 **国能 e 招、中煤、秦源、中铁鲁班、三峡** 做少量列表及详情验证；这些候选分别补充煤炭、工业装备、电力、水电和交通建设。华电和国家电投可随后验证动态栏目及公告附件。此顺序是工程验证建议，不代表已接入或已保证覆盖率。

华能、大唐、国家电网本次返回错误或超时；中石油、石化、铁建、中交存在页面提取或 JavaScript 限制，应先确认公开阅读方式或联系平台了解授权渠道。南网有明确的对接申请入口，可评估其接口是否允许用于商机展示；本次没有提交申请。

煤矿装备、通用工业设备采购已经在中煤等平台可见，但这不等于覆盖全国工业制造。钢铁、有色、汽车、船舶、航空航天和独立装备制造集团仍属于后续扩展范围。本清单也不代表这些集团所有子公司采购均集中在同一入口。

## 接入前仍须验证的项目

- 公开公告列表、详情与变更/结果是否能在保持 TLS 校验、限频、官方域名白名单的条件下稳定读取；遇到登录、验证码、403 等限制应记录并停止受限路径，不规避。
- 各采购方式和工程/货物/服务栏目分别确认分页、排序和日期；首页可见最新公告不代表全部栏目最近七日完整。
- 信息化相关性基于采购内容判定，电子采购平台名称、CA、投标软件及供应商注册模板不构成信息化采购需求。
- 区分公告公开阅读权、标书下载权限和第三方数据再利用授权；本次未发现可直接确认已获授权的公告数据 API。
- 正式启用前在项目运行环境保存少量公开证据、补解析测试，并单独给出采集验收结论。检索引擎索引和本报告不能代替该验收。
