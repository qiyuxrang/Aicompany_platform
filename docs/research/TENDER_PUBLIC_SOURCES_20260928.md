# 全国公开招采来源调研（2026-09-28）

建议采用“全国聚合入口 → 31 省官方分网 → 重点医院、高校采购人官网”的覆盖层次。全国政府采购入口不能替代工程建设招投标入口；同一项目可能在多个官方渠道同步发布，应保留来源与公告版本，不能把转载数量当作新增项目数量。

本次只核实公开网页和官方引用，没有新增采集适配器、修改运行配置、登录网站或执行批量采集。除现有 CCGP 中央／地方栏目已有有限适配外，下列其他入口均为**未接入候选**。优先级是业务价值判断，不代表已通过自动采集验证。

## 覆盖与分类建议

1. **31 省的发现与上线分开。** 从两套官方全国导航维护省级来源目录，再逐省记录官方域名、公告入口、读取状态、分页终止条件、最近成功时间与覆盖窗口。本轮列出广东、浙江、江苏、山东、四川、陕西六省示例；其他省份仅进入待核验目录，不硬编深层地址，也不标成已接入。
2. **工程、货物、服务三路保留。** 工程建设包含施工、工程设备以及勘察设计监理等公告；信息化项目还大量表现为软件开发／运维服务、系统集成和服务器等货物采购。行业是采购人业务领域，建设方向是信息化／数字化／智能化证据，采购类别是另一维度，不能互相替代。
3. **提前需求与当前招标区分。** 市场调研、采购意向、单一来源公示、采购公告、变更和结果保留各自阶段。若要扩大信息量，可新增后台阶段识别和相应展示；不应把调研、意向或中标结果混进“可投标”的数量。
4. **公告发现不等于文件下载。** 先验收公开列表→公开详情→发布时间→地区→原文链接，再检查附件是否公开。登录、CA、验证码或访问保护处应停止自动流程，保留可用的公开入口与明确原因。
5. **全国聚合不是全国全量承诺。** 全国平台已声明数据来自地方／部门；地方可能延迟同步、渠道不完整或分页受限。覆盖状态应报告实际来源与时间窗口，历史记录保留；不能因为接入一个全国站点就显示“覆盖全国全部项目”。

中国政府采购网的[数据接口规范通知](https://www.ccgp.gov.cn/zcfg/mof/202403/t20240306_21605100.htm)描述的是地方分网向中央主网申请对接，涉及公函申请及调试账号。这不能被解释为任何第三方都能无授权调用的全国抓取接口。

下一步建议先做全国公共资源平台与 CEB 平台的公开读取预检，同时用华西医院等已读到公开列表的机构站验证“需求阶段”识别；省级按实际可读性逐个上线。无论优先级如何，本文件不构成新增来源已接入或自动采集已成功的证明。
