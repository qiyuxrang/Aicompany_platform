## H3B 图片识别增量（用户已确认）

- 新增平台模型 supports_vision 能力声明（默认 false）和迁移 0014；管理后台可配置。
- 独立 /v1/generate-vision 入口，共用服务鉴权、并发和厂商安全传输；原文本入口保留 64KiB 限制。
- 只接受受限大小的内嵌 PNG/JPEG，拒绝远程 URL、非法 base64、超限和非 user 图片消息。
- 门户/模型管理测试 36 项通过，模型网关 39 项通过。均为隔离自动化，不证明真实厂商视觉兼容。
- 用户指定两份不同 PDF 本地提取已执行；样例一约 199 字且含大图，不能认定正文完整；样例二约 4800 字。
- 已实现 PDF 逐页覆盖检查、受限 JPEG 渲染及显式 recognize_pages 调用 hr_resume_extract；图片页用转写文本替换残留文本，保留页号/原件/图片/文本 hash。模型声称可读不等于人工准确性验收，结果标记 requires_visual_review。
- 覆盖判断为启发式（无文本或单图覆盖至少 25%）；可能漏掉复杂混合页，不宣称精确扫描检测。
- 两份指定真实 PDF 仅本地分页检查：样例一 1 页、199 字，标记需要视觉识别；样例二 3 页文本层均可用。未外发原文或图片。
- 文件、分页、视觉调用合同和门户模型测试合计 27 项通过，迁移无漂移。
- 演示库尚无 supports_vision 列，且无 hr_resume_extract 路由；真实视觉模型兼容与两份简历识别仍 BLOCKED，未擅自选择厂商或修改运行库。
