# 普通浏览器后台操作补验清单

本轮状态：**未执行，不能以此前内嵌浏览器截图或Django Client测试替代。** 当前浏览器工具只提供Codex In-app Browser，未发现可控的普通Chrome/Edge连接。没有安装扩展、启动个人浏览器、读取个人浏览器配置/凭据，亦没有放宽Origin/CSRF规则。

## 验证环境与数据边界

- 使用独立门户验收实例、全新隔离测试库和临时账号，不复用公司账号，不在现有日常库重置用户。
- 本轮实际使用回环18310门户、18318经营隔离实例；18210属于用户日常管理员预览，不作破坏性验收。不得影响现有8100、18210、8018及其配置。
- 本轮合成账号前缀为 `bridge_`；密码随机，仅在受限本地文件保存。旧端四文件范围已获批准。HTTP后台表单补验不改变此普通浏览器矩阵仍待执行的状态。
- 初始测试管理员通过现有bootstrap_admin建立，之后由真实浏览器完成现有Admin页面操作；不编写新管理UI，不把数据库直改当成UI成功。
- 普通浏览器需具有真实页面Origin；不能信任 `Origin: null`、关闭CSRF，或修改Cookie安全策略来使测试通过。

## 操作矩阵（以下全部待执行）

| 编号 | 操作者与真实页面操作 | 通过标准 | 需留证据 |
|---|---|---|---|
| A01 | 临时管理员登录、首次改密、重新登录 | 原密码校验有效，强制改密前不能进入Admin；旧会话失效 | 脱敏截图、HTTP状态、当前账号标识 |
| A02 | 在用户新增页创建普通产品账号 | 不出现superuser/staff自由赋权；新账号首次登录必须改密，业务入口仅产品 | 创建前后截图、对应审计ID |
| A03 | 在用户编辑页增加/移除工程角色 | 普通用户下一次请求入口变为对应并集；删去角色后直接URL/API同样拒绝 | 两个独立会话的截图与拒绝状态 |
| A04 | 在角色页修改模块授权再恢复 | 影响该角色用户而非所有用户；管理员没有因此默认获得经营模块 | 修改前后模块集、角色变更审计 |
| A05 | 管理员重置普通测试用户密码 | 两次确认；重置后用户原有两个会话失效，临时密码登录强制改密 | 重置结果、旧会话401/回登录、无密码审计 |
| A06 | 停用再启用普通测试用户 | 停用后下次平台请求拒绝；启用后须重新登录，旧会话不恢复 | 三个时点的会话结果及审计 |
| A07 | 管理员试图停用自己或移除自己管理员角色 | 页面报错，账号及角色不变，不记录虚假成功变更 | 错误提示及复核结果 |
| A08 | 审计页查询上述账号、角色及重置操作 | 可筛选/查看；无新增、保存修改、删除入口；记录不含密码、票据、服务密钥 | 查询/详情截图、操作与审计ID对应表 |
| A09 | 普通测试用户直接访问/admin/；管理员直接读取未授权经营数据 | 普通用户不能管理，管理员默认无经营权限 | 浏览器拒绝页与后端状态 |
| A10 | 普通浏览器Admin原生注销表单 | 有效同源POST及CSRF成功，后续受保护请求拒绝；GET注销不能替代 | 原生表单请求状态、注销后页面 |

## 证据与结束动作

每项记录时间、浏览器版本/实际控制方式、URL、测试角色、操作结果、截图路径、关联审计ID；未执行/失败/阻塞与通过分列。不截取填入明文秘密的DOM快照，不把随机密码、Cookie、CSRF、Authorization或票据写入报告。请求抓取仅留方法/路径/状态与非敏感断言。

验收结束停用仅本次登记的测试账号并使密码不可用，关闭测试会话；不操作任何旧系统原生正式账号。失败时也执行本次测试账号清理，不批量扫全库用户。

要解除浏览器阻塞，需要提供可控的普通浏览器连接，或由操作者按本清单手工执行并留证；后一种应明确标为人工验收，不声称智能体自动执行。工具连接就绪后，这部分不必等待旧端桥接实现，可独立补验。
