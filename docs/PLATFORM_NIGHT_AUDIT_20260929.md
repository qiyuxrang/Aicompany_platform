## 后端缺陷修复

| 范围 | 触发问题 | 修复结果 |
| --- | --- | --- |
| 公开商机 | 短暂 SQLite 写锁、来源异常使任务停留运行中 | 有界数据库重试；保存来源运行编号与已有计数，按原租约收尾；无法安全收尾时等待明确恢复 |
| 产品资料 | 下载校验期间撤权，流式回答中途撤权 | 下载打开文件前再次检查；每个回答片段输出前重新检查资料范围及配置 |
| 工作总结 | 已撤权资料任务仍出现在标题/数量中 | 复用当前输入资料授权判定过滤 |
| 人事 | 畸形 UUID/版本/action、损坏 DOCX、单简历意外异常 | 正常 4xx；有界解压；异常任务记录失败，消费者继续处理后续任务 |
| 工程 | 预检期间撤权或租约失效后继续启动测算 | 每个阶段重新核验授权、执行版本与有效租约 |
| 运维与集成 | 异常状态类型、巨大页码、非法 Unicode 票据、异常 HTTP 响应 | 返回受控错误，避免 500 或泄露底层异常 |
| 模型 | 上游返回数组/对象形式错误码 | 统一转为安全、明确的上游失败，非流式和流式接口一致 |
| 本地启动 | Windows 虚拟环境启动器退出后留下消费者子进程 | 退出时停止本次启动的消费者进程树 |

## 商机六项优化

来源扩展、30 天检查窗口、相关性分级、公开附件字段证据、项目公告归并、个人标记与参与状态，详见 [六项交付记录](product/TENDER_SIX_OPTIMIZATIONS_20260929.md)。榆林优先，随后陕西、周边和全国。保留真实来源链接与公告历史；没有截止时间或预算证据时明确待核实。

秦源公开 DOCX 的中文文件名现可正确编码下载；只对已核实的该站下载接口、DOCX 类型及文件签名兼容其特殊 MIME。实际样本 11,909 字节、提取 572 字，未把资格门槛误记成预算。

最终维护验收时保存 1,694 条来源商机记录，默认相关招采项目列表显示 236 个项目，其中榆林 18 个、陕西合计 39 个；171 条含公开附件，3 条已成功提取。默认列表 9 次数据库查询，实际检查耗时约 48 ms；数量和耗时均为验收时快照，之后随更新变化。

本轮中煤 156、国家能源 135、政府采购 387、秦源 422 条候选全部处理，单条跳过数均为 0。`PARTIAL` 来自明确的分页/范围上限。发布维护前确认没有遗留运行中批次，备份后完成字段回填、恢复来源配置并重新启动服务。

## 已知边界

公开来源有分页、数量、频率及可达性限制，来源显示部分更新不等于失败，也不能宣称全网覆盖。榆林公共资源网站在本机的 TLS 校验问题没有绕过。图片扫描件、旧 DOC、加密或外部域附件不能可靠提取时保留待核实状态。PostgreSQL 并发及部分文档运行时检查须在对应环境运行。前端构建仍有单包体积提示。真实模型、RAGFlow、工程成本 CLI 和企业台账数据各自依赖配置，未配置部分保留明确提示。
