# 产品资料：RAGFlow 分类浏览

产品事业部的「资料」入口 `/centers/product/sources` 直接展示 RAGFlow 文档，不再以项目列表代替知识库资料。项目自身的上传资料仍在项目详情中查看。

本地业务分类为 `05_产品事业部_P5工程知识库`、`02_产品事业部_项目案例与交付库`、`01_产品事业部_方案与可研库`，不包含 `03_产品事业部_清单报价库_Table`。页面根据当前账号的真实授权返回分类，不在前端硬编码库名或文档。

## 浏览与权限

- 沿用 `PORTAL_PRODUCT_KNOWLEDGE_AUTHORIZATIONS` 中逐账号、逐知识库的文档 ID 白名单；新增入库文档不会自动获得访问授权。
- 文档列表支持名称搜索、分页；打开文档可分批读取 RAGFlow 已解析的文本片段。未解析或没有可用片段时显示相应状态，不伪造正文。
- 正文按文本显示，不执行文档 HTML，不自动加载文档中的远程图片。此功能不是原始 Word、PDF 等文件的下载或完整排版预览。
- 浏览使用现有 RAGFlow 配置与访问令牌，不调用生成模型；仍遵守知识服务启用、访问许可和 URL 白名单检查。
- 列表、数量与正文均限制在账号授权范围，响应不缓存；请求结束前复核权限，防止撤权期间继续返回资料。
- 调整授权范围后，旧问答对话可能因原范围不再匹配而不可读取，需要新建对话；浏览功能不会迁移或删除对话。

## 页面布局

产品页面隐藏底部统一入口宣传和模块接入说明。资料内容充分使用主区，长列表、正文在内容区滚动，桌面侧栏保持独立；窄屏布局不依赖固定宽度。

## 接口

- `GET /api/product/knowledge/datasets/`
- `GET /api/product/knowledge/datasets/{dataset_id}/documents/?page=1&page_size=20&q=关键词`
- `GET /api/product/knowledge/datasets/{dataset_id}/documents/{document_id}/chunks/?page=1&page_size=10`

需要登录且具有产品知识库授权；未经授权的库或文档不泄露是否存在。部署时更新前后端并重启 Web 进程；授权配置留在服务端，不提交令牌或本地环境文件。
