# 在另一台电脑展示已采集商机

仓库中的 `data/demo/tender-public.json.gz` 是从实际已采集公告生成的公开历史快照。拉取代码后导入此文件，即可在另一台电脑显示项目列表、分类、地区、公告详情及公开原文链接，不必等联网采集完成，也不需要部署 RAGFlow。

演示包保留真实发布时间和截止时间，不会把历史项目改成“今日新增”或“未截止”。页面数量会随筛选条件变化；建议使用“全部行业”“招标采购”“全国”和“全部状态”，或切换“陕西省榆林市”演示重点区域。个人关注、已读和不相关标记不随包迁移。

## 已有本地环境：一条命令导入并启动

先拉取 GitHub 最新代码，停止这份仓库原来运行的 Web 服务及其采集消费者。在仓库根目录使用 PowerShell 7 执行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\import-tender-demo.ps1
```

脚本使用另一台电脑自己的 `.runtime/local.env` 和数据库，依次校验演示包、执行缺失迁移、导入公告，再复用既有依赖构建前端并启动 `http://127.0.0.1:8100`。不会安装依赖、替换整库、复制账号、重置密码或自动开启联网采集；本次启动仅在进程内关闭商机更新开关，不改写本地配置文件。

使用另一台电脑**现有且获产品事业部授权的账号**登录，进入“全国商机看板”：

```text
http://127.0.0.1:8100/centers/product/opportunities
```

重复执行只补充尚不存在的公告，不覆盖本机已有公告、版本、来源配置或个人标记。既有业务数据与账号继续保留；公告按稳定标识导入，不靠清空数据库恢复演示。请勿将这个本地演示脚本用于生产数据库。

## 新电脑首次准备

先按 README 的本地启动要求安装 Python、Node.js 等依赖。首次执行：

```powershell
.\scripts\start-local.ps1 -DisableTenderUpdates
```

此步骤初始化本机独立环境并启动基础平台，不部署 RAGFlow，也不设置账号密码。按 README 的账号流程创建管理员、配置产品部门账号与授权；如果本机已有账号则继续使用。按 `Ctrl+C` 停止服务后，再执行上面的导入命令。导入脚本在 `.runtime/local.env` 不存在时会停止并提示先完成初始化，不会静默创建另一套数据库配置。

## 校验、只导入及自定义文件

```powershell
# 只验证文件，不迁移、不写入数据库、不启动服务。
.\scripts\import-tender-demo.ps1 -CheckOnly

# 导入后暂不启动服务。
.\scripts\import-tender-demo.ps1 -NoStart

# 导入自己导出的新快照；含空格路径需要引号。
.\scripts\import-tender-demo.ps1 -InputFile 'D:\demo\tender-public.json.gz'

# 后续继续以不联网采集的模式启动。
.\scripts\start-local.ps1 -UseExistingDependencies -DisableTenderUpdates
```

需要最新公告时，在已获授权且完成来源核验的环境中单独启用采集。演示包只是导出时的历史内容；首次导入不代表本机已完成真实联网更新，来源运行状态也不应被当作本机采集成功证明。

## 文件包含的范围

仅包含公开商机展示需要的来源信息、项目字段、公告与分类证据。演示包不携带用户、密码、会话、角色授权、个人标记、私有环境配置、业务项目资料或采集任务租约。它不是数据库备份，也不替代数据库迁移。

已随包保存的文字字段可离线展示；打开官方原文或附件链接仍需要网络和来源网站可用。附件原文件及采集私有快照不打包，不能把链接当成已下载的离线文件。手工录入业务数据、知识库内容和 RAGFlow 环境均不在迁移范围内。

## 随仓库快照的实际验收

本包于北京时间 2026-09-29 07:07 导出，压缩后约 2.9 MB；包含 7 个公开来源、1,909 份公告、2,681 个公告版本、1,891 条商机记录。新建空数据库导入后，默认数字建设相关招采列表展示 263 个项目，榆林 18 个、陕西合计 40 个。总记录数与筛选后的项目数口径不同。导入第二次新增数全部为 0；没有导入账号、个人标记或运行中任务。

文件摘要与记录数量见 `data/demo/manifest.json`。可用 `Get-FileHash data/demo/tender-public.json.gz -Algorithm SHA256` 核对。日期均保留原值，演示时间变晚时，截止状态会按当前时间正常变化。
