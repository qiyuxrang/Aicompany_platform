# 产品蓝图闭环夜间长任务交付状态

记录日期：2026-09-27（Asia/Shanghai）

## 本轮结论

本轮已经完成当前电脑上能够真实完成的产品蓝图闭环，包括：

1. 上传 1 份设备清单和多份项目背景资料后的本地解析、分析进度和蓝图生成入口。
2. 蓝图人工审核；不满意时可带意见重生成，最多允许 3 次修改申请；第 4 次被系统拒绝。
3. 蓝图由任务所有人批准后，自动进入技术方案、可行性研究报告和 PPT 简版草稿三件套流程。
4. 两类长文档的目标字数、实际字数和达标状态写入任务检查点，并通过 API 和页面展示。
5. RAGFlow 正式模式采用失败关闭：没有真实检索快照时不能生成正式蓝图，不会伪造“已检索”。
6. 当前 RAGFlow 不可连接时可使用 `source_only_preview` 做来源内预览；预览不能通过正式发布门禁。
7. 大文档进入模型复核时采用有标记的受限抽样，避免超过模型网关单消息上限；系统不会把抽样复核冒充全文复核，全文仍必须人工审核。

当前实现继续使用已有的 Django 持久化任务状态机、数据库版本链和 worker，不新增 LangChain/LangGraph 运行时依赖。这样对现有项目改动最小，也最快得到可运行结果；未来接入 RAGFlow 时只需实现已经预留的知识快照接口，不需要推翻蓝图审核和三件套流程。
