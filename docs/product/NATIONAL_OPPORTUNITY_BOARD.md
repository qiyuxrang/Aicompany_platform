# 全国商机看板

## 业务范围

展示全国各地区公开招投标、采购公告中，与信息化、数字化、智能化建设相关的机会。暂不包含拟建项目、投资计划或非公开线索。全国表示地区范围，实际覆盖取决于已接入的公开来源，不代表全国所有网站的完整公告总量。

页面采用三个下拉筛选，选择后自动更新，不再要求填写关键词、采购单位或地区：

| 筛选 | 选择方式 | 默认值 |
| --- | --- | --- |
| 行业 | 多选 | 全部行业 |
| 公告类型 | 单选 | 招标／采购公告 |
| 地区 | 单选 | 全国 |

行业包括煤炭、水利水电、医疗卫生、交通运输、电力与新能源、石油与化工、市政与公共设施、教育与科研、工业制造。信息化、数字化、智能化是建设方向，在公告上展示相关标签，不与行业混为一类。

默认展示有明确相关建设内容的公告。单纯煤炭、药品、家具采购或普通土建不默认显示；含明确智能化、信息系统、安防监控等建设内容的混合项目可保留。网页中的电子招标、网上报名、下载文件等流程说明不能作为项目相关性证据。相关性不足或不能判定的公告标为待核实，行业无法判定的保留待分类，不强行归入九类之一。

## 列表与概览

看板显示符合当前条件的商机数、今日新增数和即将截止数，均采用与列表一致的筛选范围。今日新增按北京时间首次发现时间计算；即将截止指未来七天内截止。切换页码不改变概览统计。

列表和详情保留项目名称、行业、建设方向、地区、公告类型、发布时间、截止时间、预算及官方原文入口。最近更新时间来自实际采集成功记录；无记录时明确提示尚未成功更新。接口失败时提示数据可能过时，不将未知统计显示为零。

## 分类与运行

分类为可追溯的本地规则结果，不调用大模型或 RAGFlow，不代表资质审核或项目适配承诺。新公告采集时更新分类；历史公告通过离线管理命令重新分类，复用本地快照并验证完整性。读取看板不会触发抓取或修改数据库。

更新既有环境前先备份数据库，加载该环境的配置后执行：

```text
python backend/manage.py migrate
python backend/manage.py reclassify_tenders --dry-run
python backend/manage.py reclassify_tenders
python backend/manage.py backfill_tender_regions --dry-run
python backend/manage.py backfill_tender_regions
```

新增字段位于迁移 `0026_tender_opportunity_classification`。旧记录初始为待核实，执行回填后明确匹配的公告才会出现在默认看板。回填不访问外站、不修改公告原始版本，不会把维护时间算成采集更新时间；快照缺失或损坏时仍保持待核实。可重复执行回填；并发采集更新过的记录不会被较早的回填结果覆盖。

地区补齐复用公开列表中明确的省份与正文县区，例如“西藏 / 聂拉木县”，确保省级筛选可以命中。仅使用已验证快照，不根据县名猜省份；省份冲突或快照损坏时跳过并报告。规则 `digital-construction-v2` 进一步排除平台注册、获取采购文件和法规引述中的“信息化／网络安全”等流程文字。

## 持续更新

按扩大覆盖方案，采集范围默认为北京时间最近 30 个日历日（含今天），每小时检查一次，已获取历史公告保留供查看。迁移 `0027_tender_hourly_schedule` 保存调度时段和触发方式；同一小时不会重复安排定时批次，人工刷新和定时更新共用串行队列。服务启动时检查当前时段，不补发关机期间所有历史时段。

页面采用紧凑标题、三个筛选和项目商机列表，统计收为列表内一行；不再展示自动更新安排和自动更新批次横栏。最近更新时间保留在列表标题旁，来源详情和手动刷新结果位于列表下方。后台每小时采集设置保留。浏览器可见时每 30 秒同步状态，有活动批次时每 3 秒检查，隐藏页面暂停轮询。后台以独立心跳维护运行状态；失去租约会停止后续采集，避免旧进程继续写入。

新环境默认关闭外站采集、人工刷新和定时更新。经来源核验后设置 `PORTAL_TENDER_INGESTION_ENABLED=1`、`PORTAL_TENDER_MANUAL_REFRESH_ENABLED=1`、`PORTAL_TENDER_SCHEDULE_ENABLED=1`、`PORTAL_TENDER_LOOKBACK_DAYS=30`，启用相应来源并运行 `python backend/manage.py run_tender_consumer`。Windows 本地启动脚本会按这些开关启动消费者，退出时停止它，无需 Docker 或 RAGFlow。电脑关机或服务停止期间不采集；重新启动继续当前时段。

来源范围与操作命令见 [运行说明](TENDER_INTEGRATION_RUNBOOK.md)。每次扫描有页数和候选数上限，最近 30 天是日期范围，不保证已读取这个范围内全部网站和全部公告。无法验证完整性的更新明确标为部分更新；没有匹配数据时显示空状态，不注入演示公告。
