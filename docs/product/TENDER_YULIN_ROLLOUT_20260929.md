# 榆林优先商机看板落地记录

## 业务范围

从公开招采来源获取真实公告，识别信息化、数字化、智能化建设内容，以榆林为重点向陕西、内蒙古、山西、宁夏及全国扩展。无需 RAGFlow，不上传知识库、不向量化、不调用知识库检索。数据库仅保存公告、去重信息、筛选字段和获取状态。

## 本轮实现

- 新增陕煤秦源招标平台 `qinyuan`：读取官方公开招标、非招标列表及 HTML 详情。真实分页、每栏目每页最多 25 条；来源配置默认停用，本机完成真实验证后启用。
- 只读 JSON 查询严格限定为秦源公开列表端点，保留 HTTPS 校验、来源域名限制、限速和响应大小限制；禁止 POST 重定向。
- 中国政府采购网排除侧栏新闻，支持公开招标子栏目相对链接；将列表扫描与详情预算分开，按采购类型、数字建设线索和地域优先选择详情。使用持久分页进度，详情失败或租约丢失时不推进。
- 识别算力集群、ERP、智能体等明确数字建设内容，同时要求正文证据。资格登记、平台使用说明与普通工程背景不应作为建设依据。
- 地区字段采用明确标签及可信官方字段，排除政策段落污染；历史修复保留原始公告版本与获取时间。
- 默认展示全国相关公告，按榆林、陕西其余地区、内蒙古/山西/宁夏、全国其余排序；支持行业、公告类型和地区下拉筛选。超出结果范围的旧分页链接自动返回第一页。
- 标题和筛选区保持紧凑，项目列表优先呈现。

## 覆盖口径

采集窗口维持最近 7 天，已经取得的历史公告保留。窗口长度不代表全国公告已完整覆盖；有界分页仍以“部分更新”显示，不宣称全量。秦源是新增已验证来源，其他调研网站不能计入已接入来源。

秦源地区来自官方结构化省市字段与公告明确地区信息。存在采购单位属地与实际交付地不一致的可能，具体服务和交付范围仍以原公告为准。

## 本地运行

入口：http://127.0.0.1:8100/centers/product/opportunities 。使用原有授权账号登录。

启动仍用 `scripts/start-local.ps1 -UseExistingDependencies`，Web 服务与消费者由同一启动脚本管理。采集开关、独立公告快照目录及业务数据库沿用本机配置；未改变账号密码、角色或知识库配置。

本轮修改前已使用 SQLite backup 保存完整备份：`.runtime/backups/local-dev-before-expansion-20260929-002619.sqlite3`。运行状态及验收结果保存在 `.runtime/expansion-*.json` 和 `.runtime/expansion-*-tests.log`，均为本机运行文件。

## 最终验收

2026-09-29 本轮两次实际刷新后，共保存 436 条公告；默认相关采购列表 48 条，其中陕西 7 条、榆林 3 条。这是当时已取得且匹配的数量，不代表当地或全国全部项目。默认排序、榆林/陕西筛选、越界页返回首页及列表原文链接均通过接口核验。

使用真实业务数据库的隔离副本完成浏览器验收：榆林下拉得到 3 条记录，神木智能体项目详情显示正确采购单位、编号、地区和官方原文入口。验收账号仅存在于副本中；正式账号密码及角色与备份逐项比较一致。页面截图保存在 `.runtime/yulin-real-projects.png`。

验证结果：后端全量 722 项（6 项跳过）通过；随后最终字段回填、稳定公告标识、地区、接口回归 52 项通过。前端全量 313 项通过，最后布局与地区修改的 39 项相关测试通过，TypeScript 与生产构建通过。全量后端测试对临时测试账号使用测试专用快速哈希，未修改本机服务的密码配置。

秦源字段维护可用 `backfill_qinyuan_fields --dry-run` 预览后执行，采购单位、项目编号、金额和采购方式只从校验通过的快照重新提取，保留原始版本和获取时间。重新解析同一官方公告时使用已建立的公告身份，避免编号修正产生重复商机。
