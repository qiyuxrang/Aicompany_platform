# 产品事业部「商机获取」接入验收记录

记录日期：2026-09-28。目标分支：`codex/tender-end-to-end`。本记录区分隔离环境代码验证、真实来源、企业证据和正式部署；没有证据的阶段不得写为通过。

## 已做的隔离验证

- 复用独立原型的四来源适配、安全出站、归一化、快照/版本/去重和刷新批次，迁入平台 Django/React 产品工作台；采集和人工刷新默认均为 `0`，不需要新的 Tender 登录角色。
- 在专用、无宿主持久卷的 PostgreSQL 17 容器上，执行目标仓库空库迁移、合并主线 `0024_engineering_job` 和 Tender `0024_tender_product` 后应用 `0025_merge_engineering_tender`；`makemigrations --check --dry-run` 无漂移。该容器与实际业务库无关。
- Tender 定向测试（API、归一入库、模型、出站门禁、固定日期窗口、默认关闭、刷新及来源幂等登记）使用隔离环境通过；离线 fake adapter 证明点击入队、消费者处理、数据库出现结构化公告和局部扫描不冒充全量。
- 合并最新 `main` 后，前端 296 项测试、TypeScript 检查和生产构建通过；隔离 PostgreSQL 浏览器冒烟验证产品账号能从侧栏进入「商机获取」，真实空状态、刷新不可用提示和零外站请求。浏览器截图仅保存在本地忽略目录 `.runtime/tender-validation/opportunities-empty.png`，不是生产环境截图。
- `docker compose --profile tender config --quiet` 已通过隔离占位环境的语法检查；profile 默认不启动，未执行部署。

## 未通过或不能代替的验收

- 全量后端 `portal.tests` 的 PostgreSQL 回归在运行 240 秒后超时，没有全量通过结论。针对性 63 项回归中有 1 项现有产品资料下载用例因 PostgreSQL 连接关闭失败；同一用例在**未接入 Tender 的当前 `main`**、相同独立 PostgreSQL 上也复现，属于本次变更之外的既有失败，不在 Tender 分支偷改。其余定向用例通过；故不能写“后端全量无回归”。
- 快速后端全局脚本 `qa/run_prd_tests.py --fast-passwords` 因此隔离 worktree 未安装独立的 `product-parser-python` 和 `product-documents-python` 运行时出现 15 个失败、5 个错误；并非本功能用例，但不能作为全量通过证明。实际运行前仍需按仓库既有安装说明准备这些运行时。
- **B 未验收**：没有实际访问或抓取任一外站，不存在此目标平台真实公告的业务核验结果。固定初采窗口为北京时间 `[2026-09-26 00:00, 2026-09-29 00:00)`；截至 2026-09-28 窗口尚未结束。四站逐站许可、完整扫描边界和发布时间仍需证据。没有可信全量边界应记 `PARTIAL/NOT_VERIFIED`，不得扩大窗口或用原型旧库数据顶替。
- **C 未验收**：Compose 只定义可选 Tender 消费者和私有卷，未开正式开关、未运行正式消费者、未迁移业务库或部署。缺生产备份恢复、监控、出站和业务签收证据。
- 离线 5A 规则内核支持条件分类与严格证据判断（证据缺失、失效或等级不可比返回待确认），仅提供本地代码和测试；没有证据库、证据权限、API 或界面，不可作为企业资质预审已上线。
- **S2/S3/S4 未验收**：企业资质原件/有权审核人、文件取得及模型/检索外发许可、新站点独立许可未提供。任何离线规则不能转为用户可见的“满足”结论；不自动报名、投标或创建正式文档。

## 后续门槛

1. **正式来源 B**：每站确认栏目、条款、频率、可保存字段/附件、停止条件和负责人；在固定日期窗口结束后检查可证实的覆盖范围及官方原文，产出至少一条可核对的目标平台公告，或逐站报告无合格数据。
2. **运行 C**：完成目标环境备份/恢复、私有存储、消费者在线/故障报警和回退，获得部署授权后方可开启独立开关与消费者；生产按钮仅在真正有消费者时可用。
3. **资格与扩源**：先有企业证据的对象权限/核实人/有效期与人工决定规则，再分别实施公告预检、完整文件复核及逐站扩源；未经授权不移植独立原型的证书下载接口或上传文件。

代码审查/合并只意味着默认关闭的功能进入代码库，不构成 B、C 或资格阶段业务批准。运行说明见 `docs/product/TENDER_INTEGRATION_RUNBOOK.md`。
