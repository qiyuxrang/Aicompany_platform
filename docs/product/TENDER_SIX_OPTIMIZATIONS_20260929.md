# 商机看板六项优化交付记录

本次范围：公开招投标商机，以陕西榆林为优先地区，向周边及全国扩展。使用公告数据库保存来源和版本，不接入 RAGFlow，不要求知识库入库。

## 已实现

1. 新增榆能集团电子采购交易平台、中煤招标与采购网、国家能源集团招标网。连同既有秦源、中国政府采购网、陕西交控来源，共同提供公开公告。来源记录见 `docs/research/TENDER_PUBLIC_ENERGY_INTEGRATION_20260929.md`。
2. 默认采集窗口由近 7 天扩至近 30 天，历史公告保留。列表依次按榆林、陕西、邻省及全国排序；同地区优先未截止、待核实，再到已截止项目。单次采集仍有分页和数量上限，部分覆盖不会显示成全网覆盖。
3. 数字项目分为“核心相关”和“包含相关内容”。正文必须有建设/采购证据，门户登录、文件上传、投标资质等用语不能单独使普通项目变成数字商机。
4. 在数据库事务外提取公开 PDF、DOCX、TXT 附件；保留来源、摘要、提取状态。补充预算、采购范围、文件获取及截止时间。未知、无明确时分、相互冲突的时间保持待核实；预算不能从供应商业绩门槛推断。
5. 明确项目编号、相同采购单位及相同标包/轮次建立项目组。原始公告、版本、官方链接全部保留；不按相似标题跨站合并。详情展示同项目全部公告，延期截止参与状态计算。不同标段、包号和二次招标分别处理。
6. 新增每用户独立的已看、重点关注、不相关状态。打开详情自动标记已看；不相关默认隐藏，可以恢复。筛选状态写入 URL。统计展示当前批次新增项目，重复公告不作为新项目计数。

## 数据及页面

页面：`http://127.0.0.1:8100/centers/product/opportunities`。保留紧凑标题、行业/公告类型/地区下拉；个人标记和参与状态是一行简短控件。用户无需填写采集字段。

数据库新增迁移：`0028_tender_project_groups_and_user_state`、`0029_tender_extraction_evidence`。维护命令 `backfill_tender_public_fields` 和 `group_tender_projects` 从已验证快照回填字段、构建项目分组，保留原采集时间和版本历史。

已公开确认的榆林实例包括：柠条塔基于智能体的主煤流设备维护及调速优化、榆树湾主运系统煤流智能调速改造、银河煤业井下主排水配电柜与软启动柜智能化改造。数量以验收时实际 API 结果为准。

## 验证与限制

后端、前端测试包含来源实际 HTML/JSON 固定样本、分页/日期校验、PDF/DOCX 提取、用户隔离、标包分离、延期及二次招标、个人标记及恢复操作。UI 在真实数据库的隔离副本中验收，不修改用户密码和现有授权。

榆林公共资源网站的本机 HTTPS 证书校验问题尚未解决，未绕过校验，也未记作已接通。扫描 PDF、旧式 DOC、加密文件及来源域名范围外的附件不能可靠自动提取时保留待核实说明。新增能源来源本轮优先覆盖公开招标频道，不能据此宣称覆盖这些网站所有公告类别。
